# Exploratory Data Analysis (EDA) – Titanic Dataset

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic passenger dataset to identify patterns, relationships, trends and anomalies using Python.

## Objective
To gain practical experience in data exploration, statistical analysis and data visualization.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
The Titanic dataset contains passenger information such as:
- Passenger ID
- Age and Gender
- Passenger Class
- Ticket Fare
- Family Information
- Embarkation Port
- Survival Status

## Tasks Performed
1. Imported and explored the dataset.
2. Checked dataset dimensions and data types.
3. Analyzed missing values and duplicates.
4. Performed data cleaning and feature engineering.
5. Conducted univariate analysis.
6. Conducted bivariate analysis.
7. Performed multivariate analysis using pairplots.
8. Created correlation heatmaps.
9. Identified outliers and skewness.
10. Generated meaningful insights and conclusions.

## Visualizations
- Histograms
- Count Plots
- Boxplots
- Scatterplots
- Pairplots
- Correlation Heatmaps

## Key Findings
- Passenger survival patterns differed by gender.
- Passenger class showed differences in survival rates.
- Ticket fares contained potential outliers.
- Age and fare distributions showed different patterns.
- Family size provided additional insights into survival.

## Project Files
- `Task_5_Titanic_EDA.ipynb` – Complete analysis and Python code.
- `Titanic_EDA_Report.pdf` – EDA findings report.
- `titanic_cleaned.csv` – Cleaned dataset.
- `train.csv`, `test.csv`, `gender_submission.csv` – Original datasets.

## Conclusion
The project demonstrates how Exploratory Data Analysis helps understand datasets, discover meaningful patterns and generate insights through statistical methods and visualizations.
